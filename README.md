# LIA Frontend Test – HTML & CSS Accordion

A clean, responsive accordion/dropdown component inspired by the expandable product information sections on the ASICS product page.

## Overview
This project was built as part of a LIA application test assignment.

### Requirements
- HTML & CSS only
- No JavaScript
- 4 expandable sections
- Smooth open/close CSS animation
- Responsive design

## Features
- CSS-only accordion functionality
- Smooth dropdown transitions
- Minimal, modern e-commerce inspired UI
- Mobile-friendly layout
- Accessible semantic structure
